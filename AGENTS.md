# Aviary contributor notes

Read `docs/requirements.md`, `docs/architecture.md`, `docs/verification.md` and `docs/tickets.md` before changing product behavior. The README describes the current implementation; the documents distinguish implemented behavior from V1 acceptance and open decisions. Record engineering choices in `docs/decisions.md` and actual verification and limitations in `docs/verification.md`.

Aviary is a trusted-network, single-user service: participant labels route traffic but do not authenticate or authorize it. Preserve the default loopback listener and do not claim encryption or access control. Acknowledgment must follow durable storage; retain stable submission identities and distinguish unknown outcomes from acceptance. Preserve existing SQLite records and coordinate protocol changes across the service, CLI, terminal and portable skill.

Use `cargo test --locked` for Rust tests. After building, `python3 tests/terminal_pty.py` exercises the terminal and `python3 tests/skill_smoke.py` executes the portable skill examples; both need loopback access. `python3 tests/decision_slice.py` exercises the local decision waiter, terminal and restart path; `python3 tests/attention_smoke.py` checks mixed-agent attention classification; `python3 tests/terminal_reconnect.py` tests local terminal recovery across a service restart; `python3 tests/terminal_partial_refresh.py` checks independent refreshes when a page cannot be read; `python3 tests/startup_smoke.py` exercises startup from an isolated directory; `python3 tests/storage_limit.py` tests a Linux per-process file-size failure and recovery in a disposable database; `python3 tests/default_listener.py` inspects the default service listener on Linux, skipping if its port is occupied; `python3 tests/cli_reference.py` runs the CLI reference workflow; `python3 tests/cli_stdin.py` checks bounded stdin and a near-limit submission; `python3 tests/history_terminal.py` exercises the terminal history view; `python3 tests/zeromq_interop.py` exercises a direct Python/libzmq client when system libzmq is available. `python3 tests/tmux_smoke.py` additionally exercises a decision in an isolated tmux server and requires tmux. Process-kill tests and local pseudo-terminals do not prove OS-crash recovery, remote operation or representative operator validation. Preserve existing uncommitted work and avoid changing a paused goal without a new instruction.
